## 5. 錯誤／邊界處理與重測紀錄
- **邊界情境**：當查詢問題在離線規則下沒有命中任何預設關鍵字（例如改寫題「`這場讀書交流辦在哪個空間？`」或文件外問題「`火星的平均氣溫是多少？`」），問題向量為全零 `[0.0, 0.0, 0.0, 0.0]`。
- **預期與實際處理**：
  - 在 `cosine_similarity` 中，若任一向量長度（norm）為 `0`，直接回傳 `0.0` 避免除以零（`ZeroDivisionError`）。
  - 在 `rank_chunks` 中，先檢查 `if not any(query_vector): return []`，確保問題向量全零時直接回傳空清單 `[]`，不會因為 `min_score = 0.0` 而硬塞分數為 `0.0` 的無關片段。
  - 在實作 `TODO A` 時，使用 `hit = dict(item)` 複製來源字典再寫入 `"score"`，確保不會汙染原本的 `chunks` 資料結構，並通過第 5 節 `A自我檢查` 所有斷言。
