# 第9週範例檔（Notebook與App共用）

| 檔案 | 內容 | 用途 |
|---|---|---|
| `sample.txt` | UTF-8，三段虛構活動說明：活動日期2026年11月11日、每組4人、共8組、總名額32人 | 直接讀檔、清理、切塊與原文核對 |
| `sample.csv` | UTF-8-SIG，5欄（活動、日期、時間、地點、名額）、6筆虛構活動；地點`圖書館,討論室`、`創客空間,第二區`以引號包住 | 示範引號內的逗號，以及「一列當一個檢索單位」 |
| `sample.pdf` | 2頁中文文字層，不是掃描檔 | 逐頁抽取，核對日期、時間與名額；不能用來驗證OCR |
| `sample.docx` | 中文段落與表格交錯 | 核對「段落 → 表格 → 段落」的本文順序 |

內容皆為虛構教學活動，無真實個資或機密。PDF／Word的活動日期為2026年11月11日、時間14:00至16:00，報名截止11月6日；每組4人、8組、總名額32人。CSV另含11月3日至17日的多筆活動。文件都沒有提供費用或報名網址。

- **App：**資料來源選「內建範例」，從下拉選單直接選檔。
- **Notebook：**把四個檔案複製到Notebook所在的資料夾（`week09/`）；Colab直接上傳。範例程式只寫檔名。

這四個檔案由`scripts/build_week09_revised.py`從`week09/sample_tata/`複製而來；要修改範例內容，請改原檔後重建，兩邊才會一致。
